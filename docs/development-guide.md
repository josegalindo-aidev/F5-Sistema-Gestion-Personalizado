# Guía de desarrollo

- Python 3.11+ y entorno virtual.
- Seguir Ruff para lint y formato.
- Usar nombres descriptivos en inglés para código y módulos.
- Añadir type hints en interfaces y funciones públicas.
- Mantener funciones pequeñas y con una responsabilidad.
- No subir secretos, bases de datos locales ni temporales.

## Definition of Done
- Criterios de aceptación satisfechos.
- Tests relevantes añadidos y pasando.
- Ruff sin errores.
- Documentación actualizada.
- PR revisado y aprobado.
- Integración en `main`.
